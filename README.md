# Accounting Cycle Portfolio
A project from [Harisenin.com](https://www.harisenin.com/) Accounting & Tax Bootcamp. This project demonstrates a complete, end-to-end accounting cycle for a simulated business. It showcases the ability to process raw financial transactions, perform period-end adjustments, and generate presentation-ready financial statements using spreadsheet software. 

# Skills & Tools Demonstrated
* **Accounting Principles:** GAAP compliance, Double-Entry Bookkeeping, Accrual Accounting, Financial Reporting.
* **Spreadsheet Modeling:** Advanced Excel formulas, data validation, automated financial statement linking, and professional formatting.
* **Analytical Skills:** Trial balance reconciliation, adjusting journal entries, and financial performance analysis.

## 📂 Repository Structure
* `/spreadsheets` - Contains the core `.xlsx` workbook including the Unadjusted Trial Balance, 10-Column Worksheet, and Ledger accounts.
* `/reports` - Presentation-ready PDF exports of the final Income Statement and Balance Sheet.
* `/data` - The initial source transactions and adjustment data used to build the model.

## 🔄 The Accounting Workflow Implemented
1. **Journalizing & Posting:** Recording initial business transactions.
2. **Unadjusted Trial Balance:** Verifying that total debits equal total credits.
3. **Period-End Adjustments:** Calculating and applying accruals, deferrals, depreciation, and prepayments.
4. **10-Column Worksheet:** Centralizing the accounting flow from unadjusted figures to adjusted balances.
5. **Financial Statement Generation:** Dynamically generating the **Income Statement**, **Statement of Owner's Equity**, and **Balance Sheet**.
